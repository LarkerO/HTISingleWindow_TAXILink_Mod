# TAXILink 0.5.2

正式发布说明。发布源码与构建产物不等于远端部署；请在维护窗口按下述步骤升级。

## 本版内容

报价并行预算与可读错误、多乘客端并行登录、多云图片存储、品牌与轮播、主页在线玩家位置；模组下客保护、人工车门/空车清除、占轨协助及车厂复用；console 菜单按运营流程排序。

## WebSocket 审查

模组连接使用异步握手（10 秒超时）、指数退避、有界发送队列（256）和发送超时；失败不等待网络恢复，不阻塞 Minecraft Simulator。修复同步异常导致 connecting 标记无法释放，关闭时改用 shutdownNow，避免 HttpClient.close 等待挂起请求。SM2 子进程最多等待 3 秒，在传输/异步发送线程执行。

浏览器 WebSocket 为异步 API，断连不会卡住 JavaScript 线程；Vue v1 保留 4 秒 HTTP 轮询及 5 秒重连，新增请求互斥防止慢请求堆叠，捕获构造错误。TMUI Web 行程已有请求互斥与页面离开清理，原生行程由 HTTP 查询维护；网络不可用时会显示错误/旧数据，不代表车辆已停止。不能用断开管理网页代替急停。

## 0.5.1 升级与保留数据

1. 暂停新接单，等待活动行程完整回库、支付/退款稳定；停止旧业务进程与游戏实例后备份。完整保留数据库、SQLite runtime/WAL、installation（含 settings.key、SM2 密钥及锁）、.env/外部密钥、游戏存档及 taxilink-state；保留原云桶对象与静态目录备份。
2. 替换业务代码，安装 composer 生产依赖；不要访问 /install、不要 seed、不要删除卷。在 backend 执行 php bin/console.php migrate；容器使用原 compose 项目和卷运行该命令。失败不得启动新版。
3. 迁移采用数据库锁防止并发 DDL；SQLite 在独立事务中迁移，失败回滚。MySQL DDL 隐式提交，发生中断可在处理原因后重复执行；保留每个已存在的表/列。PostgreSQL 使用会话 advisory lock。不要在业务事务中执行迁移，不要边迁移边运行旧进程。
4. 旧账号、订单、支付和图片地址不重建；system_settings/route_cache、OAuth 可空字段、订单跟踪字段及 MySQL 大 JSON 类型升级按需补齐。轮播/多云配置使用已有配置表，缺失配置自动降级。不承诺回滚旧数据库能保留升级后的订单：回滚代码时保留最新数据库。
5. 同步更换后端、管理台、v1/v2 静态文件及 0.5.2 对应加载器模组。无侧边站台登车需要玩家客户端也安装 TAXILink，停车轨道/Platform 寻路记录仍需保留。v2 独立工程的变更在 integrations/passenger-v2/overlay。
6. 对比升级前后账号/订单/支付数量与历史金额，重复 migrate 再核验。测试登录、报价、下单、回库、订单追踪、图片及轮播后恢复接单；保留备份至验收完成。

## 已知边界

真实 BlueMap 3D 上游仍有加载停滞，不能视为已完全修复；提供单地图隔离与失败恢复 2D。云存储真实凭据上传、真实 Minecraft 客户端无站台登车仍需部署环境验收。SQLite 本地回归已覆盖；当前没有可用 MySQL/PostgreSQL 实例时，不将代码审查当成真实数据库验收。此前 PENDING 文档为阶段历史记录，以本说明为本版升级入口。
